# 05 · Deployment, Verification, and Rollback

> English version of [05-部署验证与回滚.md](05-部署验证与回滚.md).

## 1. Prerequisites

- EFI partition mounted (default `/Volumes/EFI`). This machine's main-disk EFI is `disk0s1`, mountable via Disk Utility.
- If the system has multiple EFI partitions, use `--esp` to specify the main-disk one explicitly.

## 2. Three-Step Deployment

Run in the `02-efi-oc/` directory:

```bash
cd SN6140-Hackintosh-Audio/02-efi-oc

# Step 1: read-only check of current state
python3 deploy_sn6140.py --check

# Step 2: dry-run the changes (no writes)
python3 deploy_sn6140.py --dry-run

# Step 3: actual deployment (auto backup + atomic write + post-write verification)
python3 deploy_sn6140.py
```

The script does 5 things:

1. Back up config.plist + AppleALC.kext to `EFI/OC/backups/sn6140-audio-<timestamp>/`
2. Replace `EFI/OC/Kexts/AppleALC.kext` with the custom kext
3. boot-args: `alcid=11` → `alcid=15`, add `alcdelay=1000`
4. HDEF `layout-id` / `alc-layout-id`: int 11 → data 15
5. Disable `SimpleHDA.kext`

Specify another mount point:

```bash
python3 deploy_sn6140.py --esp "/Volumes/EFI 1"
```

## 3. Verification After Reboot

```bash
bash ../03-tools/verify_audio.sh     # run in 02-efi-oc/
# or from project root: bash 03-tools/verify_audio.sh
```

Equivalent manual commands:

```bash
# 1. Confirm the custom AppleALC is loaded
ioreg -r -n AppleALC -l -w0 | grep VersionInfo
# expected: DBG-199-2026-10-26

# 2. Confirm audio devices appear
system_profiler SPAudioDataType
# expected: audio output devices appear (built-in speakers / headphones)

# 3. Confirm AppleHDADriver is matched (no longer !matched)
ioreg -r -c AppleHDADriver -l | head -20
```

**Safety first**: for the first playback, set volume to minimum, confirm no harsh noise, then raise gradually. If crackling occurs, mute immediately and roll back.

## 4. Rollback

Method A — script rollback (recommended):

```bash
python3 deploy_sn6140.py --rollback
```

Method B — use restore.sh in the backup directory:

```bash
sh /Volumes/EFI/EFI/OC/backups/sn6140-audio-<timestamp>/restore.sh /Volumes/EFI
```

Both restore the original config.plist and official AppleALC.kext, effective after reboot.

## 5. FAQ

| Symptom | Possible cause | Fix |
|---|---|---|
| Still no sound after deploy | Wrong EFI mount point (deployed to USB EFI) | Confirm `disk0s1`, use `--esp` for main disk |
| `alcid=15` not taking effect | boot-args overridden by other config | Check whether OpenCore has another NVRAM Add override |
| Sound works but volume keys don't | layout config lacks volume control | Switch layout (community provides 15/16/17 alternatives) |
| No sound after sleep/wake | codec init timing | Increase `alcdelay` (e.g. 2000) |
| Harsh noise | pin config mismatch | Roll back immediately, switch layout |
| linker assertion (when building) | No full Xcode | See [04-编译指南.md.en.md](04-编译指南.md.en.md) |
| Sound → Input shows only the default device, no headset mic | Microphone input ports are not customized in this version (intended scope) | Not a fault; for microphone support use a separate branch, see [README](../README.md.en.md) |
