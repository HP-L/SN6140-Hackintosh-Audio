# 05 · 部署、验证与回滚

## 1. 前置条件

- EFI 分区已挂载（默认 `/Volumes/EFI`）。本机主盘 EFI 为 `disk0s1`，可用磁盘工具挂载。
- 若系统有多个 EFI 分区，用 `--esp` 明确指定主盘那个。

## 2. 部署三步曲

在 `02-efi-oc/` 目录执行：

```bash
cd SN6140-Hackintosh-Audio/02-efi-oc

# 第一步：只读检查当前状态
python3 deploy_sn6140.py --check

# 第二步：预演将要做的改动（不写入）
python3 deploy_sn6140.py --dry-run

# 第三步：实际部署（自动备份 + 原子写入 + 写后验证）
python3 deploy_sn6140.py
```

脚本会做 5 件事：

1. 备份 config.plist + AppleALC.kext 到 `EFI/OC/backups/sn6140-audio-<时间戳>/`
2. 用定制 kext 替换 `EFI/OC/Kexts/AppleALC.kext`
3. boot-args：`alcid=11` → `alcid=15`，加 `alcdelay=1000`
4. HDEF 的 `layout-id` / `alc-layout-id`：int 11 → data 15
5. 禁用 `SimpleHDA.kext`

指定其他挂载点：

```bash
python3 deploy_sn6140.py --esp "/Volumes/EFI 1"
```

## 3. 重启后验证

```bash
bash ../03-tools/verify_audio.sh     # 在 02-efi-oc/ 目录下执行
# 或在工程根目录: bash 03-tools/verify_audio.sh
```

手动等价命令：

```bash
# 1. 确认加载的是定制版 AppleALC
ioreg -r -n AppleALC -l -w0 | grep VersionInfo
# 期望: DBG-199-2026-10-26

# 2. 确认系统出现音频设备
system_profiler SPAudioDataType
# 期望: 内置扬声器 / 耳机 / 内置麦克风

# 3. 确认 AppleHDADriver 已匹配（不再是 !matched）
ioreg -r -c AppleHDADriver -l | head -20
```

**安全第一**：第一次播放先把音量调到最低，确认没有刺耳噪声再慢慢调高。若出现爆音立即静音并回滚。

## 4. 回滚

方式 A —— 脚本回滚（推荐）：

```bash
python3 deploy_sn6140.py --rollback
```

方式 B —— 用备份目录里的 restore.sh：

```bash
sh /Volumes/EFI/EFI/OC/backups/sn6140-audio-<时间戳>/restore.sh /Volumes/EFI
```

两者都会恢复原始 config.plist 和官方版 AppleALC.kext，重启后生效。

## 5. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 部署后仍无声 | EFI 挂载点选错（装到了 U 盘 EFI） | 确认 `disk0s1`，用 `--esp` 指定主盘 |
| `alcid=15` 不生效 | boot-args 被其他配置覆盖 | 检查 OpenCore 是否还有其他 NVRAM Add 覆盖 |
| 有声音但音量键无效 | layout 配置不含音量控制 | 换 layout（社区提供 15/16/17 备选） |
| 睡眠唤醒后无声 | codec 初始化时机 | 加大 `alcdelay`（如 2000） |
| 刺耳噪声 | pin 配置不匹配 | 立即回滚，换 layout |
| linker assertion（编译时） | 无完整 Xcode | 见 [04-编译指南](04-编译指南.md) |
